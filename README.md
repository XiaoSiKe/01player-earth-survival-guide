这份攻略来自「零一玩家｜01PLAYER」，一个以大学生为主要群体、面向全社会开放的 AI 共创社区。我们把现实生活看作开放世界游戏「地球Online：零一玩家」。每个人都是自己故事的主角，在实践中探索与成长，完成自己的从零到一。

**「不当牢玩家！不做NPC！」**

> [!IMPORTANT]
> 这份攻略是一套装在支持 Agent Skills 的 AI 助手里的 Skill。安装后，在对话里带来一段课程材料、一个待核实的结论或一个小项目，就能开始。攻略会按你的基础、时间和设备，在讲解、示范、练习和反馈中陪你推进。

## 用这份攻略做什么

无论你的专业、年级或 AI 基础如何，都可以从自己关心的问题出发，练习理解新技术、解决现实问题，逐渐形成自己的判断和实践能力。

攻略把思考方法、学习科学与 AI 实践结合起来，也能陪你理清大学生活中的选择与行动困难。

先用通俗的话和熟悉的例子讲清楚，再根据反馈逐渐加深。卡住时换例子或示范，需要时再练习、检查理解。

## ↗ 开始使用

### 01 / 安装

[下载 0.3.2 安装包](01player-earth-survival-guide.zip)

解压后，将整个 `01player-earth-survival-guide` 文件夹放入以下目录。升级前备份本地改动。

| 使用环境 | 安装位置 |
| :--- | :--- |
| macOS / Linux | `~/.agents/skills/01player-earth-survival-guide/` |
| Windows | `%USERPROFILE%\.agents\skills\01player-earth-survival-guide\` |

<details>
<summary><strong>使用命令行安装，或从旧版升级</strong></summary>

也可使用 [Skills CLI](https://github.com/vercel-labs/skills#install-a-skill) 安装，并选择目标 AI 助手：

```sh
npx skills add XiaoSiKe/01player-earth-survival-guide --skill 01player-earth-survival-guide
```

默认安装到当前项目，跨项目使用时添加 `-g`。升级时将旧版移出技能搜索目录，避免重复加载。

</details>

### 02 / 打开新聊天，带来一个问题

```text
使用 $01player-earth-survival-guide。
我刚上大学，没有编程基础，今晚有 20 分钟，想试一次 AI 帮助课程学习。请直接带我开始。
```

也可以直接说：“用「零一玩家」地球生存攻略，帮我理清下一段该学什么。”

### 03 / 带着结果继续

带回答案、卡点或变化了的条件，一起调整下一步；换聊天时，用可复制的续接小结继续。

用已有工具即可开始，具体费用以所用 AI 助手为准。

### 三种常见的帮助

| 你带来的问题 | 攻略怎样帮你 | 关注的结果 |
| :--- | :--- | :--- |
| **“我不会编程，想用 AI 学懂一段课程材料。”** | 用当前设备和可用时间选一个小任务，边做边讲任务表达、上下文和结果核对 | 做成一次尝试，并能解释其中一个关键判断 |
| **“AI 帮我做完了，但我讲不清。”** | 找到具体卡点，给解释或示范，再用变化任务检查；需要时暂时撤去辅助 | 分开记录作品能否使用、本人能否独立完成 |
| **“大家都在学，我不知道该选什么。”** | 分清目的与手段，比较真实任务、前置条件和代价，用有限体验补信息 | 得到有依据的暂定方向，也可以调整、暂停或停止 |

## ◇ 思想与方法

从已读的哲学原著、学习研究与 AI 教学资料中提炼方法，转化为具体的提问、练习与反馈。阅读范围和采用位置均可查阅。

### 调查、实践与自主选择

| 来源与提炼的方法 | 在学生场景中怎样用 |
| :--- | :--- |
| **《实践论》** · 毛泽东<br>在实践与认识之间往返，承认可靠的间接经验 | 把“我适不适合”暂作假设，通过可承受的体验增加信息，再修正判断 · [P01](01player-earth-survival-guide/references/thinking.md#p01) |
| **《矛盾论》** · 毛泽东<br>研究具体条件，识别阶段重点，允许重点变化 | 查看课程、项目、生活问题的期限和相互影响，选当前重点并保留必要保障 · [P02](01player-earth-survival-guide/references/thinking.md#p02) |
| **《反对本本主义》** · 毛泽东<br>调查实际情况，检查脱离条件的结论 | 区分事实与解释，找正式材料和具体经历，不照搬一个成功故事 · [P03](01player-earth-survival-guide/references/thinking.md#p03) |
| **《我们怎样思维》第六章** · 杜威<br>界定问题、提出解释、推演与观察检验 | 为一次失败寻找其他可能原因，用证据决定补基础还是换方法 · [P03](01player-earth-survival-guide/references/thinking.md#p03) |
| **《论自由》第三章** · 密尔<br>个性发展、生活试验与他人利益边界 | 尊重本人认可的目标和责任，允许兴趣、收入、照护与生活平衡并存 · [P04](01player-earth-survival-guide/references/thinking.md#p04) |
| **《手册》第一节** · 爱比克泰德<br>区分由己与非由己的事 | 承认感受，分清能直接行动、能协商影响和暂不能改变的部分，寻找现实支持 · [P05](01player-earth-survival-guide/references/thinking.md#p05) |
| **自我决定理论** · Ryan 与 Deci<br>自主、胜任和关系需要 | 检查目标是否认同、难度与支持是否合适，不把困难一概归因为不够努力 · [P06](01player-earth-survival-guide/references/thinking.md#p06) |

以上是《毛泽东选集》等原著相关章节的方法启发，保留历史语境；任务与“三类行动范围”等应用由本项目设计。

另有 **[目的与路径对应](01player-earth-survival-guide/references/thinking.md#p07)**、**[同等条件下比较选择](01player-earth-survival-guide/references/thinking.md#p08)** 和 **[小试验与机会成本](01player-earth-survival-guide/references/learning-action.md#l08)**：围绕本人目标，比较真实任务、投入与未知，允许调整和停止。

### 学习科学与行动方法

| 方法与学习安排 | 怎样检查 |
| :--- | :--- |
| **提取练习与间隔学习** · Dunlosky 等；Roediger 等<br>看懂后合上材料尝试回答，核对纠错，再隔一段时间重试 | 能否在延迟后提取关键知识；间隔按目标和错误调整 · [L01](01player-earth-survival-guide/references/learning-action.md#l01) |
| **自我解释与有用笔记** · Dunlosky 等<br>用自己的话说明因果与步骤，标记不懂处，保存来源和疑问 | 解释是否正确、是否有依据；熟悉和流畅不直接算掌握 · [L02](01player-earth-survival-guide/references/learning-action.md#l02) |
| **例题学习与迁移** · Sweller 与 Cooper<br>从合适的完整示例进入，再补步骤、独立练习、改变条件 | 会跟做之后，能否处理新的表示或情境 · [L03](01player-earth-survival-guide/references/learning-action.md#l03) |
| **有支持的问题学习** · Hmelo-Silver<br>用真实有限问题识别知识缺口，结合范例、教师或同伴支持 | 成果是否解决问题，个人能否解释关键决定 · [L04](01player-earth-survival-guide/references/learning-action.md#l04) |
| **自我调节与元认知校准** · Zimmerman；Dunlosky 与 Rawson<br>设具体目标，对照自我预估与实际表现，调整策略 | 分开“接触过、看懂了、可独立使用”，必要时换题或延迟复测 · [L05](01player-earth-survival-guide/references/learning-action.md#l05) |
| **按真实容量安排时间** · Aeon 等<br>课程、兼职、照护和休息先占位，为少量重点留缓冲 | 比较计划与实际，删减、协商或调整；不以压缩睡眠补进度 · [L06](01player-earth-survival-guide/references/learning-action.md#l06) |
| **实施意图** · Gollwitzer 与 Sheeran<br>把明确行为接到实际会出现的情境：“当……，我就……” | 查清没开始时是目标、材料、疲惫还是情境不合适 · [L07](01player-earth-survival-guide/references/learning-action.md#l07) |

**帮助可以充分，掌握要另行检查。** 根据卡点解释或示范，再用变化任务或延迟检查，观察能否独立完成。

## ◎ 三条路径，六类任务

从表达任务、核实输出等共通基础开始，再按需要选择路径；已有能力可以跳过。

| 路径 | 从什么需要开始 | 留下什么证据 |
| :--- | :--- | :--- |
| **专业应用** | 课程理解、资料核对、表达或重复工作 | 能解释依据、识别无根据补充，并在自己的材料上复用 |
| **应用开发** | 一个输入输出清楚的小功能或小工具 | 能运行样例、解释关键部分，亲手修改并检查结果 |
| **模型与研究** | 理解方法、比较结果、解释局限 | 能提出可比较问题，区分观察与解释，说明反例与未验证处 |

[选择起点、四个可跳过的阶段与一份主材料 ↗](01player-earth-survival-guide/references/ai-pathways.md)

| 任务 | 一次练习留下什么 |
| :--- | :--- |
| **[01 · 学懂一段材料](01player-earth-survival-guide/references/ai-practice.md#t01)** | 理解题、本人答案与一次纠错，再用变化题检查 |
| **[02 · 核实一个结论](01player-earth-survival-guide/references/ai-practice.md#t02)** | 主张、出处与判断，保留仍然未知的部分 |
| **[03 · 做有限问答](01player-earth-survival-guide/references/ai-practice.md#t03)** | 基于公开资料的小成果，检查有答案、无答案与冲突情况 |
| **[04 · 修改一个小功能](01player-earth-survival-guide/references/ai-practice.md#t04)** | 需求、可运行样例和一次有原因的修改 |
| **[05 · 体验不同路线](01player-earth-survival-guide/references/ai-practice.md#t05)** | 用同一主题体验应用、开发与研究，记录帮助、兴趣和困难 |
| **[06 · 比较专业方向](01player-earth-survival-guide/references/ai-practice.md#t06)** | 把目的、真实日常、前置能力、投入与体验连接起来 |
